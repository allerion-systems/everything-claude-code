## Summary

The markdown + git knowledge system that underpins everything — serving both
[Allerion](allerion-overview.md) and the [R&B estimating workflow](../roofing/estimating-workflow.md).

## Key Points

- Substrate: markdown notes + git, readable by Claude Code, NanoClaw, and local models.
- Ingest YouTube/links/docs into structured notes via `npm run brain:ingest`.
- A 3D visualizer renders these notes as an interactive knowledge graph.
