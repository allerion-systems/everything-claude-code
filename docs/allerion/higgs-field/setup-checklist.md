# Higgs Field — Channel Setup Checklist

Step-by-step to create and brand the channel. The account creation needs your Google login (manual);
everything else here is fill-in-the-blanks from `channel-strategy.md`.

---

## 1. Create the channel
- [ ] Sign in to YouTube with the **business Google account** (not personal). Create a **Brand
      Account** channel named **Higgs Field** (Brand Account = others can be added as managers later).
- [ ] Handle: **@HiggsField** (or `@HiggsFieldAI` / `@HiggsFieldTrades` if taken).
- [ ] Add Allerion as a channel manager so the team can post.

## 2. Brand it (Allerion colours: black #040506, olive #5a6850, silver #9da2a6)
- [ ] **Profile picture:** Higgs Field mark on black.
- [ ] **Banner (2560×1440, safe area 1546×423):** name + tagline (e.g. "AI, explained for people
      who build things") + "by Allerion" + allerion.io. Generate in the brand palette.
- [ ] **Watermark:** small logo, bottom-right, for subscribe prompts.

## 3. About + links
- [ ] **Description:** who it's for (trades owners), what they'll get (plain-English AI, no hype),
      and the soft CTA: free Digital Brain Starter at allerion.io.
- [ ] **Links:** allerion.io, the free Starter, email info@allerion.io.
- [ ] **Business email** set for enquiries; **location** = your service area.

## 4. Structure for discovery
- [ ] **Playlists by pillar:** "AI Explained (Plain English)", "Real Before & After", "Tool
      Teardowns", "Building Allerion (Build-in-Public)".
- [ ] **Channel trailer** for non-subscribers: a 45–60s cut of Script 1's hook + best proof moment.
- [ ] **Sections** on the homepage: trailer → most-popular → each pillar playlist.

## 5. Shorts strategy
- [ ] Every long video → 2–3 Shorts (the strongest 20–40s moments — usually the "Proof" segment).
- [ ] Vertical 9:16, hook in the first 2 seconds, captions burned in (sound-off viewing).
- [ ] Link each Short to its long video; use the content skill to generate them in batch.

## 6. Upload defaults (set once)
- [ ] Default description template (pain → what they'll learn → Starter link → tags) — see
      `channel-strategy.md` SEO section.
- [ ] Default to a branded end screen (subscribe + "watch next" + link).
- [ ] Pinned comment template with the free-Starter CTA.

## 7. How it "connects to" the Allerion system / the Higgs field
- [ ] Every video's CTA points to the **free Digital Brain Starter** — the on-ramp into the
      digital brain (`DDC.../digital-5d-brain/`).
- [ ] Tag a UTM on the link (e.g. `?utm_source=youtube&utm_campaign=higgsfield`) so Starter signups
      are attributable to the channel.
- [ ] Each client engagement → a case study (`digital-5d-brain/templates/project-case-study-template.md`)
      → a "Real Before & After" video. The proof loop *is* the connection: jobs feed the channel,
      the channel feeds jobs.

## 8. First-week actions
- [ ] Record Scripts 1–3 (`first-videos-and-scripts.md`) in one session.
- [ ] Run the content skill to cut Shorts + draft LinkedIn/X posts.
- [ ] Publish video 1 + trailer; schedule 2 and 3; post the first Shorts.
