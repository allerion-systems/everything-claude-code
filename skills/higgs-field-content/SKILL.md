# Higgs Field Content

One job in → a week of content out. This is thin orchestration over skills that already exist —
its value is the **Higgs Field format and funnel discipline**, not new generation code.

## When to Activate

- A job, before/after, or live demo is ready to become content
- You filmed a long video and need Shorts + posts from it
- You want the next week's teaching content for the channel

## Reuses (do not rebuild)

- `skills/content-engine/SKILL.md` — platform-native scripts, YouTube structure, calendars.
- `skills/video-editing/SKILL.md` — cut a long recording into Shorts (scene/highlight extraction).
- `skills/crosspost/SKILL.md` — adapt one idea into platform-native LinkedIn/X variants.
- `skills/ai-consulting-playbook/SKILL.md` — the teaching framework (analogies + 60-second proof)
  that defines *how* to explain, so videos teach instead of pitch.
- `DDC.../digital-5d-brain/agents/agent-stack.md` (Content agent) and
  `digital-5d-brain/templates/project-case-study-template.md` ("Content angles") — the source capture.

## The format (every drop follows this)

**Hook → Teach (one idea, one analogy) → Proof (show real files/results) → soft CTA (free Digital
Brain Starter).** No hard selling. The teaching is the marketing. See
`docs/allerion/higgs-field/channel-strategy.md`.

## Workflow

1. **Capture the source.** Take the job/proof. If a case study exists, pull it; else fill the
   `project-case-study-template.md` "Content angles" section (the YouTube idea + short + post are
   half-written there).

2. **Pick the pillar + the one idea.** Map to a pillar (teach-one-concept / real before-after /
   tool teardown / build-in-public) and the single AI concept the viewer should leave with. Choose
   the analogy from the playbook (receptionist / talking filing cabinet / apprentice).

3. **Write the long-form script** via `content-engine`, in the channel format above. Title to the
   *pain in their words* (see the strategy doc's SEO section), not to "AI".

4. **Cut Shorts (2-3).** Take the strongest 20–40s moments — usually the Proof segment — and write
   vertical 9:16 Short scripts (hook in 2s, captions for sound-off). If real footage exists, use
   `video-editing` to extract the clips.

5. **Spin off posts** via `crosspost` — a LinkedIn post and an X thread, platform-native (never the
   same text twice), each ending in the same soft CTA.

6. **Output a content drop**, clearly separated:
   - `LONG VIDEO` — title + full script + description (with the Starter UTM link) + tags.
   - `SHORTS` — 2-3 scripts with hooks.
   - `POSTS` — LinkedIn + X variants.
   - `PUBLISH NOTES` — suggested order/schedule for the week, and the proof artifact to screen-record.

## Guardrails

- **Teach, don't pitch.** If a draft sounds like an ad, cut back to one taught idea + one proof.
- **Always show real proof.** The signature segment is real files answering real questions.
- **One CTA, kept identical** across the drop (free Digital Brain Starter) so it compounds.
- Keep the Allerion brand voice and colours (black `#040506`, olive `#5a6850`, silver `#9da2a6`).
