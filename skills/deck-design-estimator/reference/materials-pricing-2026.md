## 10. Labor

National averages. Higher in coastal urban markets; lower in rural Midwest/South.

| Phase | $/sq ft of deck |
|-------|------------------|
| Demolition (if applicable) | $2 – $5 |
| Footings + posts | $3 – $6 |
| Framing | $4 – $7 |
| Decking install | $3 – $6 |
| Railing | $2 – $4 (or $20-40/linear ft) |
| Stairs | $40-80/riser |
| Features (per feature) | varies; see Features table |
| **Total labor (typical full build)** | **$11 – $22 / sq ft** |

Solo skilled carpenter: $50-90/hour. GC overhead + crew: typically billed as $/sqft above.
