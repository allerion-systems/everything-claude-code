AEC software is overdue for an unbundling.

Bexel Manager, Procore, AutoDesk Construction Cloud, Trimble Connect — every part of construction estimating sits behind a five-figure per-seat license, a closed Power BI template, or a sales call. None of them speak to AI agents. None of them are open.

The pieces to do this in the open already exist. Cesium for 3D. IFC for building data. OpenStreetMap for geometry. DDC CWICR for cost rates. The Model Context Protocol for putting it all in front of an LLM. Allerion is what happens when you connect them.

What you get

One MCP server. Every part of the loop.

3D viewer, your choice of tiles

Google Photorealistic 3D Tiles where available, OpenStreetMap Buildings everywhere else. Same Cesium scene either way.

Autonomous OSM takeoff

Footprint + levels + materials pulled straight from OpenStreetMap tags. The agent fills in what OSM is missing from the viewer screenshot.

Live cost API · 55K items

Open DDC CWICR database (CC-BY-4.0) for material, labor, equipment per unit. Strict unit matching so you never get road-sign rates for concrete.

Bexel-style 5D dashboard

Totals cards, Cesium viewer color-coded by classification, per-element cost table, three doughnut charts. Rendered inline in chat as an MCP App.

Real IFC2X3 export

A valid STEP file with IfcBuilding → IfcBuildingStorey → perimeter IfcWallStandardCase + flat IfcSlab. Loads in BIMvision, BIMcollab Zoom, Revit.

MCP-first, agent-ready

Seven tools, three prompts, three resource URIs, tool annotations. Stdio for local. Streamable HTTP for marketplace. Both share one handler.

Install

Two minutes from clone to first estimate.

Claude Desktop / Cursor / VS Code MCP

Drop this into your MCP config (`~/Library/Application Support/Claude/claude_desktop_config.json` on macOS).

{
  "mcpServers": {
    "allerion": {
      "command": "node",
      "args": ["/absolute/path/to/allerion/dist/server.js"],
      "env": {
        "MAPBOX_TOKEN": "..."
      }
    }
  }
}

Build locally

One npm install, one npm run build, you're done.

git clone https://github.com/jalleeeee/everything-claude-code
cd everything-claude-code/allerion
npm install
cp .env.example .env  # fill in MAPBOX_TOKEN
npm run build
npm start             # stdio for local clients
# or:
npm run start:http    # Streamable HTTP on :8788/mcp
npm run start:all     # http + static viewer

As a Claude Code plugin

allerion/.claude-plugin/plugin.json bundles the MCP server plus the allerion-estimator subagent, the /allerion slash command, and the allerion-5d skill. Once the parent repo is published to a Claude Code marketplace, install it as a single plugin. 

# inside Claude Code, once published
/plugin install everything-claude-code
/allerion 1600 Pennsylvania Ave NW

Remote (Claude Apps / hosted)

Point at any URL serving the Streamable HTTP transport.

{
  "mcpServers": {
    "allerion": {
      "type": "http",
      "url": "https://allerion.example.com/mcp"
    }
  }
}

Health check: GET /healthz returns {ok, version, sessions}.

Where this goes

One MCP server today. A portfolio of vertical apps next.

  1. v0

    Allerion Measure + 5D Estimation

    Address → viewer → autonomous takeoff → live cost API → Bexel-style dashboard → IFC2X3 export. Shipped.

  2. v0.1

    IFC import + clash detection

    Bring your own Revit/ArchiCAD IFC via web-ifc. Multi-discipline clash overlay. Pitched roof detection from the photogrammetry mesh.

  3. v0.2

    4D scheduling + Earned Value

    Gantt with construction-sequence animation. Earned Value, Cash Flow, Payment Certificate dashboards — the rest of the Bexel template gallery, open-sourced.

  4. v0.3

    Hosted SaaS + team workspaces

    Run your own cost book. Share sessions with collaborators. Stripe metering per estimate. Free tier stays generous.

  5. v1.0

    The Allerion portfolio

    Flightpath · drone mission planning. Climate · environmental overlays. Fleet · multi-site reporting. Tour · real-estate walkthroughs. All MCP-first.
